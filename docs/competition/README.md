# Materiały konkursowe — wersja do przeglądu

Polska prezentacja ma 9 slajdów. Lokalne nagranie MP4 pokazuje działający prototyp; nie jest testem na prawdziwym iPhonie. Materiały nie zostały przesłane ani opublikowane.

- `kazdy-krok.pdf`: problem, grupa docelowa, demo, źródła i niepewność, AI, architektura, biznes i dalsze kroki.
- `demo.mp4`: lokalna demonstracja, do 3 minut, z polskimi napisami.
- [Opis projektu](PROJECT.md): tekst do dostosowania do formularza HackTribe.

Identyfikator zespołu nie został podany; należy dodać go w formularzu zgłoszenia. Trzeba potwierdzić wagi oceniania z mentorami i wyjaśnić nazwę innego projektu w załączniku dotyczącym praw autorskich. Nie zaakceptowano umów i nie przeniesiono praw.

Oryginalne kryteria wymagają otwartego repozytorium filmu. Regulamin wymienia MP4. Publikacja wymaga osobnej instrukcji użytkownika; lokalny plik jest gotowy do przeglądu.
